YouTube Clone

A simple and responsive **YouTube Clone** website built using **HTML, CSS, and JavaScript**.

This project is created to practice frontend web development concepts such as webpage structure, CSS styling, responsive design, JavaScript functionality, and user interactions.

## About the Project

The YouTube Clone is a frontend website inspired by the YouTube user interface.

It provides a YouTube-like experience where users can browse videos, search for videos, and interact with different elements of the website.

The project focuses mainly on creating a clean, responsive, and interactive frontend using basic web technologies.

##  Features

###  Home Page

* Displays multiple video cards.
* Shows video thumbnails.
* Displays video titles, channel names, and views.
* YouTube-style layout.

###  Search

* Users can search for videos.
* JavaScript is used to filter or display matching videos.


### ▶️Video Page

* Users can select a video from the homepage.
* Displays the selected video and related information.

### 🎨User Interface

* Clean YouTube-inspired design.
* Buttons, icons, video cards, and navigation elements are styled using CSS.

##  How to Run the Project

### Step 1: Download or Clone the Repository

```bash
git clone https://github.com/ManittrishaKasnaboina/youtube-clone.git
```

### Step 2: Open the Project

Open the project folder in **VS Code**.

### Step 3: Run the Website

Open `index.html` in your browser.

You can also install the **Live Server** extension in VS Code and click:

**Right Click → Open with Live Server**

The website will open in your browser.

##  Deployment

The project can be deployed using **Vercel**, **Netlify**, or **GitHub Pages**.

### Deploy using Vercel

1. Upload the project to GitHub.
2. Open Vercel.
3. Connect your GitHub account.
4. Select the `youtube-clone` repository.
5. Click **Deploy**.
6. Vercel will provide a live website URL.
